### Apartado 1: Crear cuenta en GitHub y crear "Hola Mundo"

En este apartado se pide crear una cuenta en GitHub, en nuestro caso, ya disponemos de una cuenta `aquilinogarcia` por lo que haremos uso de ella.\
Crear un nuevo repositorio, [este](https://github.com/aquilinogarcia/PIA_Tarea01), e incluir el fichero README.md\
Editar el fichero README.md, añadiendo la descripción de la tarea.\
Crear el Ejemplo "Hola Mundo" en lenguaje de programación Python.
```Python

# Fichero python, para la Tarea01

def saludar():
    print("¡Hola Mundo!")

def saludar_nombre(nombre):
    print(f"¡Hola, {nombre}!")

saludar()
saludar_nombre("Python")
```
